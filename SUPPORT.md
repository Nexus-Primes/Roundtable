# Getting help

1. **Read [Something went wrong?](README.md#something-went-wrong)** in the README: a mod isn't loading, the game won't start, a friend can't join. The common ones are there.
2. **In Roundtable, run the checks.** Press **Why won't it start?** on the mod's page, or open **Tools > Health and storage > PC check (Doctor)**. They say what is wrong in plain words, and most problems have a button that fixes it.
3. **Still stuck?** Open an issue with the [bug form](https://github.com/Nexus-Primes/Roundtable/issues/new/choose). Include the Roundtable version (bottom right of the window), the mod and its version, and the
   text from **Report a problem...** (it hides your Windows user name and never includes your Nexus key).

| For | Go to |
|---|---|
| A bug | [Issues](https://github.com/Nexus-Primes/Roundtable/issues/new/choose) |
| An idea | [Issues](https://github.com/Nexus-Primes/Roundtable/issues/new/choose) (the feature form) |
| A security problem | The **Security** tab, *Report a vulnerability* (private): [SECURITY.md](SECURITY.md) |
| A correction to what Roundtable knows about a mod | A pull request on [`feed/recipes.src.json`](feed/recipes.src.json), or an issue |

Only the latest release is supported. Update from inside Roundtable first; many problems are already fixed.
